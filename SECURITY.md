# Security policy

This project reads local text parameter and topology files and can optionally invoke a user-selected LAMMPS executable. Treat all input files and executable paths as untrusted unless you control their source.

Do not run the converter with elevated privileges. Review generated files before using them in automated HPC workflows.

For security-sensitive reports, open a GitHub issue only if disclosure is appropriate for a public repository. Do not include licensed parameter databases, credentials, cluster hostnames, access tokens or private project data in a report.
